# Study on the HongIk Road
## Concepts of Programming Languages Study

팀장: 권영우
팀원: 최민석, 고다현, 소휘찬, 김태빈, 김연아

### 학습 목표 
스터디를 통해 전공 과목의 개념을 체계적으로 정리하고 매 주차 정기적인 토론과 심화 문제 풀이를 통해 전공 이해도를 높이는 것을 목표로 합니다. 또한, 부족할 수 있는 전공 내용이나 학업 정보를 서로 공유하며 학기 동안 꾸준한 학습을 통해 학업 성취도를 향상시키고자 합니다.

### 학습 방법
본 스터디는 교재와 강의 자료를 기반으로 개념 정리, 문제 풀이, 토론 중심의 학습을 진행할 예정입니다.
특히 홍익대학교의 다양한 학습 공간을 적극적으로 활용하는 것을 스터디의 주요 운영 방식으로 설정하였습니다.
홍익대학교에는 단체 스터디를 진행하기에 적격인 장소들이 많습니다.
따라서, 다양한 교내 학습 공간을 직접 활용하며 스터디를 진행함으로써 학교 시설을 자연스럽게 익히고 효율적인 학습 환경을 찾는 데에도 도움이 될 것으로 기대합니다.
학습 자료는 클라우드 시스템을 활용하여 공유하고, 스터디 시간에는 사전 학습한 내용을 바탕으로 브레인스토밍과 토론 중심의 그룹 학습을 진행하여 다양한 관점에서 문제를 분석하고 이해도를 높이는 방식으로 학습을 진행하고자 합니다.
